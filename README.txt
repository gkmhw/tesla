TESLA & MAGNETISMO
=================

Abra index.html no navegador. O site usa vários arquivos HTML ligados a um único style.css e script.js.

Páginas:
- index.html
- campo-magnetico.html
- motor-inducao.html
- corrente-alternada.html
- bobina-tesla.html
- transmissao.html
- cientistas.html
- conceitos.html
- impactos.html
- linha-do-tempo.html
- conclusao.html

As fotos históricas carregam do Wikimedia Commons quando houver internet. Os diagramas e animações principais são feitos com HTML/CSS/JS, sem bibliotecas externas.

O conteúdo textual foi organizado com base no material fornecido para a apresentação, mantendo as ideias e a linha do tempo daquele material.
